# ききとり しじ（MieeL）

「あかい ボールを はこに いれて」などの ことばの しじを きいて、そのとおりに うごかす アプリです（特別支援教育向け・iPad / iPhone）。

## できること（6レベル）
1. えらぶ（もの）「ほしを タッチ して」
2. えらぶ（いろ＋もの）「あかい ボールを タッチ して」
3. うごかす「くるまを かごに いれて」
4. うごかす（いろ＋もの＋ばしょ）
5. 2つ つづけて（じゅんばんどおりに）
6. かずも「きいろい ボールを 2こ おさらに のせて」

- うごかしかたは ドラッグ／タッチ→タッチ（てさきが むずかしい 子も）
- 🔊 で なんかいでも きける（きいた かいすうも きろく）
- まちがえたら「いろ」「もの」「いれもの」「じゅんばん」の どれが ちがうか おしえる。もじ・えの ヒントを だす タイミングは せっていで
- ⭐ と きろく（子どもごと）
- **A4 プリント**：ききとり ぬりえ（せんせいが よむ しじ つき・こたえ つきも）
- 🏠 ボタンで いつでも さいしょへ（ゲーム ちゅうは ながおし）

きろくは この たんまつの なかだけに ほぞん し、インターネットには おくりません。
